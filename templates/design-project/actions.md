# Actions

The project's single action list. Meeting files keep a plain record of what was assigned; this file holds the live version.

Format, one item per line:

`- [ ] 行動內容 | 負責人：姓名 | 期限：日期 或 TBD | 來源：[meeting file or sync link]`

## Open

- [ ] [行動內容] | 負責人：[姓名] | 期限：YYYY-MM-DD | 來源：[meetings/YYYY-MM-DD-meeting-name.md](meetings/YYYY-MM-DD-meeting-name.md)

## Done

Completed items, with the completion date.

## Rules

- **The checkbox here is the only live one.** Ticking it in Obsidian is how an action is completed.
- **A ticked item moves to Done** with its completion date. Never delete an item.
- **Every item links to its source**, so the reason it exists can be found later.
- **An action with no owner or deadline** is written with `TBD` in that field, not left out.
