## Status

| Status | Meaning |
| :--- | :--- |
| `Open` | Still unanswered and still worth tracking |
| `Open (review asked YYYY-MM-DD)` | It stayed open through 3 meetings. The user was asked once whether to keep, park or chase it |
| `Parked (YYYY-MM-DD)` | Set aside. It is no longer brought up, and it comes back by itself if a meeting raises it again |

The rules for this are in section 10 of `templates/shared/RULES.md`.
